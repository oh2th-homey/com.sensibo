# Sensibo

For Sensibo Sky, Sensibo Air, Sensibo Pure and Sensibo Room Sensors.

To install:

1. Get an API-key from https://home.sensibo.com/me/api
2. Set the API-key during pairing of the device

## Notes

- **Room Sensor as the primary sensor:** when a Room Sensor is set as an AC's primary sensor in the Sensibo app, the AC device in Homey shows the Room Sensor's temperature and humidity, and its *Use Room Sensor* indicator shows Yes. The primary sensor can only be chosen in the Sensibo app: the Sensibo API doesn't support changing it, so it isn't possible to control it from Homey.
